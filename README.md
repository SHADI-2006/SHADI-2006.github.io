# معرض الأعمال (Portfolio) + السي في

موقع شخصي بيعرض مشاريعك بالصور والفيديوهات والتصاميم، وصفحة سي في بتتولّد من **نفس البيانات**
وبتنحفظ PDF بصفحة A4 وحدة. عربي/إنجليزي، ليلي/نهاري، وبيشتغل على الموبايل.

```
index.html          الموقع
cv.html             السي في (افتحها واضغط «حفظ PDF»)
data/content.js     ← كل النصوص والمشاريع: عدّل هون بس
data/media.js       بيتولّد تلقائياً من مجلد media (لا تعدّله بإيدك)
media/<المشروع>/    صور وفيديوهات كل مشروع
media/gallery/      تصاميم وصور مش تابعة لمشروع
tools/build_media.py  بيقرا مجلد media وبيحدّث المعرض
```

## 1. عبّي الناقص (مهم قبل ما ترسل السي في)

افتح `data/content.js` وعبّي:

- `email` — الإيميل (بدونه ما في زر تواصل ولا إيميل بالسي في)
- `links.linkedin` — رابط لينكدإن
- بـ `timeline`: الجامعة والاختصاص وسنوات الدراسة (الحقول يلي بين `[أقواس]`)
- بـ `languages`: مستوى الإنجليزي
- `links.github` للمشاريع يلي إلها ريبو عام (SYROBIX، pdf2word_ar)
- اختياري: `photo` صورة شخصية (`media/profile.jpg`) و`phone`

أي حقل فاضي أو لسا فيه `[...]` **ما بيطلع** لا بالموقع ولا بالسي في، وصفحة السي في بتعرضلك
شريط أصفر فيه شو الناقص.

## 2. شوف الموقع على جهازك

دبل كليك على **`serve.bat`** وبيفتح `http://localhost:8080`.
(أو افتح `index.html` مباشرة — كل شي بيشتغل إلا فيديوهات يوتيوب.)

## 3. ضيف صور وفيديوهات وتصاميم

1. حط الملفات بمجلد المشروع، مثلاً `media/syrobix-rescue/`.
2. دبل كليك على **`update_media.bat`** — خلص، بتطلع بالمشروع وبالمعرض.

قواعد التسمية:

| | |
|---|---|
| الترتيب | حسب الاسم، فرقّمها: `01-...jpg`، `02-...jpg` |
| تصميم | إذا الاسم أو المجلد فيه كلمة `design` → بينحط بقسم «تصاميم» |
| فيديو | `.mp4` / `.webm` — وإذا حطيت صورة بنفس الاسم (`demo.mp4` + `demo.jpg`) بتصير غلافه |
| يوتيوب | بـ `content.js` حط `links: { video: "https://youtu.be/..." }` أو ضمن `media` |
| وصف الصورة | بـ `captions` جوّا المشروع: `"02-xxx.jpg": { ar: "...", en: "..." }` |

> الفيديو الأكبر من ~20MB الأفضل ترفعه على يوتيوب (Unlisted) وتحط رابطه — GitHub ما بيقبل ملفات فوق 100MB.

## 4. مشروع جديد

بـ `content.js` انسخ بلوك مشروع وغيّر الـ `id` (نفس اسم مجلده بـ `media/`)، والعنوان والوصف
و`highlights` (شو عملت) و`tech`. `featured: true` بيخليه بالواجهة.

## 5. السي في

افتح `cv.html` (أو زر «السي في» بالموقع) ← **حفظ PDF / طباعة** ← اختار «Save as PDF»
وشيل ✓ «Headers and footers». بتقدر تبدّل عربي/English من الزر فوق.
بيحاول يضبّ كل شي بصفحة وحدة لحاله (بيقلّل النقاط إذا ما وسعت). فيه QR بيفتح الموقع،
وكل مشروع إله رابط مباشر لصوره وفيديوهاته.

## 6. انشره على الإنترنت مجاناً (GitHub Pages)

1. على GitHub اعمل ريبو **عام** اسمه بالضبط: `SHADI-2006.github.io`
2. ارفع **محتويات** مجلد `portfolio` (مش المجلد نفسه) — من الموقع: *Add file → Upload files*، أو:

   ```bash
   cd portfolio
   git init
   git add .
   git commit -m "Portfolio"
   git branch -M main
   git remote add origin https://github.com/SHADI-2006/SHADI-2006.github.io.git
   git push -u origin main
   ```

3. *Settings → Pages → Branch: `main` / `(root)`* ← Save.
4. بعد دقيقة أو دقيقتين: **https://shadi-2006.github.io** — هاد الرابط يلي بتحطه بالسي في ولينكدإن.

إذا سمّيت الريبو اسم تاني، عدّل `site.url` بـ `content.js` (منه بيطلع الـ QR والروابط بالسي في).

روابط مفيدة: `?lang=en` بيفتح الموقع إنجليزي، و`#project/ytarabic` بيفتح مشروع مباشرة.
